# Gabay Pricing Decision Support

כלי תומך החלטה לשיווק דירות: המנוע הדטרמיניסטי מחשב אומדנים, תרחישים ושערי החלטה מהתמהיל ונתוני השוק. מנתח AI ומבקר טענות אופציונליים מוסיפים פרשנות ואינם משנים מחירים או אישורים. זה אינו שמאות, תחזית מכירות או אישור מחיר.

## התקנה והדגמה מקומית

```bash
cd poc
uv sync --locked
uv run --locked python -m gabay_pricing.web
```

להדגמה שאומתה ללא רשת, כולל ניתוח AI שנשמר קודם, ראו [DEMO_READINESS.md](DEMO_READINESS.md). היא דורשת קובצי נתונים פרטיים שאינם כלולים במסירה. הממשק הרגיל לעיל נפתח ב־`http://127.0.0.1:8765`: מצב נתונים שמורים משתמש ב־`poc/data/snapshots/market-live.json` ורק בכתובת הרשומה בו; מצב נתונים עדכניים אוסף מחדש דרך רשת ועשוי לצרוך קרדיטים. ודאו הרשאות ותנאי שימוש לפני איסוף נתונים.

ניתוח AI חדש הוא בחירה מפורשת בממשק; הוא שולח נתוני ראיות ל־Groq או לספק חלופי שהורשה במפורש, ומבצע גם בדיקת טענות באמצעות מודל. ודאו זכויות העברת נתוני צד שלישי, מגבלות ותשלום לפני הפעלתו. בדיקת המודל היא חוות דעת ולא אימות עובדתי. כשל AI אינו משנה את המחירים המחושבים. התוכנה מיועדת להפעלה מקומית בלבד.

בדיקות מקומיות: `cd poc && uv run --locked pytest -q -rs`. בדיקות המשתמשות בתמהיל ובצילום שוק פרטיים מדולגות אם הקבצים אינם זמינים. ההדגמה הדטרמיניסטית כוללת 39 דירות; תהליך AI חי לכל 39 הדירות לא הוכח כמלא.

נדרשים Python ‏3.12 ו־[uv](https://docs.astral.sh/uv/); `poc/uv.lock` נועל את התלויות. להדגמה נדרשים snapshot וראיות שסופקו בנפרד. מפתחות ספק נדרשים רק להרצת AI חדשה, ואינם נדרשים לשחזור הלא־מקוון. קובץ התמהיל המקומי ב־`DATA/חוברת1.xlsx` אינו כלול בענף המוגש; נדרש קובץ מורשה בנפרד. נתוני שוק מקוריים אינם כלולים משום שזכויות ההפצה שלהם לא אומתו. בהיעדר מפתח או בכשל Groq המחירון עדיין מופק, ושלב ה־AI מסומן כלא זמין.
