# Gabay Pricing Decision Support

כלי תומך החלטה למחלקת שיווק: תמהיל דירות → נתוני שוק → השוואות → אומדן והתאמות → תרחישים → שערי החלטה → דוחות וניתוח AI נפרד. המנוע הדטרמיניסטי אינו שמאות ואינו מנבא מכירות. אין טענה שתמהיל 39 הדירות מייצג מלאי של בניין אמיתי. קובץ התמהיל המקומי אינו כלול בענף המוגש; זכויות ההפצה שלו לא אומתו.

## התקנה והרצה ראשית

נדרשים Python ‏3.12 ו־[uv](https://docs.astral.sh/uv/); קובץ `uv.lock` נועל את התלויות. לנתוני השוק נדרש snapshot נפרד שאינו כלול בריפוזיטורי בשל זכויות ספקים שטרם אומתו. התקינו באמצעות `uv sync --locked`. הדגמת שחזור לא־מקוונת עם AI שמור, ללא מפתחות וללא רשת, מתוארת ב־[DEMO_READINESS.md](../DEMO_READINESS.md). הפקודה הבאה היא דוגמה **לניתוח AI חדש ברשת**, לא להדגמה הלא־מקוונת; היא דורשת `GROQ_API_KEY` ב־`.env` והרשאות מתאימות:

```bash
cd poc && uv run --locked gabay-pricing report --snapshot /path/to/market-snapshot.json --ai --groq-key-source dotenv --reports reports/pricing
```

קובץ ה־Excel המקומי והמדיניות הפעילה נטענים כברירת מחדל, אם הקובץ סופק בנפרד. ניתן להעביר `--workbook` או `--config` חלופיים תואמי הסכמה. כתובת ותאריך השוק נלקחים מה־snapshot; `--address` אופציונלי ומאמת התאמה. פלט מרכזי: `reports/pricing/MARKETING_DASHBOARD.html`, `pricing_results.json`, קובצי CSV, `AI_ANALYSIS_HE.md` ו־`RUN_MANIFEST.json`.

אפשר גם לבחור **במפורש** מפתח ממשתנה הסביבה באמצעות `--groq-key-source env`. אין fallback שקט בין מפתח הסביבה לקובץ, ואין לכתוב מפתחות בפקודה או בדוחות. השימוש ב־`--ai` הוא opt-in לשליחת נתונים מובנים מינימליים ל־Groq; ללא הדגל אין קריאת רשת ל־AI. לפני השימוש יש לוודא הרשאות שימוש והעברת נתוני צד שלישי.

## מה ה־AI עושה

לאחר חישוב המחירים, Groq מקבל גרסה מצומצמת של EvidencePack לכל דירה שנבחרה ומייצר פרשנות, השוואת אסטרטגיות ופעולות המשך. ברירת המחדל היא עד שלוש דירות לפי טיפוס וחומרת חסמים. ניתן לבחור IDs באמצעות `--ai-apartments 1,5,36` ולקבוע מגבלה באמצעות `--ai-max-units`. נשלחים כינויים זמניים לראיות ללא כתובות, פרטי קשר או תוכן מודעות גולמי; פרטי המקור המלאים נשארים בקובץ התוצאות המקומי.

פלט השירות מוגבל ל־JSON schema: פרשנות איכותנית וטענות כמותיות מסוגים קבועים בלבד. בכל טענה כמותית המודל בוחר מזהה שדה מורשה, והמערכת ממלאת את הערך מה־EvidencePack; אין לקבל ערך מספרי שסיפק המודל. ספרות בפרוזה נדחות; אין רשימת חריגים לביטויים בעברית. מבקר LLM בודק את מסקנות האנליסט מול הראיות שצוינו לכל טענה. אם המבקר נכשל או מסמן טענה כלא נתמכת, הפרשנות מוסתרת בדוח. המבקר אינו מוכיח נכונות סמנטית, ואין הבטחה שמספרים במילים בפרוזה יזוהו; נדרש אימות אנושי. ה־AI אינו משנה מחיר, מדיניות או אישור; כשל שירות אינו משבית את התמחור.

יש להבחין בין **תרחיש מחיר מחושב** של המנוע, **העדפה אסטרטגית מותנית** של ה־AI לבחינה בלבד, **המלצת פתיחה** העוברת שערי החלטה, ו־**אישור מחיר אנושי**. אף אחד מהם אינו הופך פרשנות AI לעובדה מאומתת. ללא יעד עסקי מוגדר של החברה וראיות שוק מספקות, אין לקבוע איזו אסטרטגיה מיטבית.

לבדיקת איכות אופציונלית בלבד קיים מבקר LLM נפרד, שאינו מופעל בתמחור ואינו מקור אמת. לדוגמה, מתוך `poc/` אפשר להריץ `PYTHONPATH=src .venv/bin/python scripts/evaluate_ai.py --saved reports/groq-fact-live-5b/pricing_results.json --unit 5 --case-ids selected_sales_present,no_sales --output reports/ai-evaluation/critic.json`. הוסיפו `--offline` להשוואת בדיקות דטרמיניסטיות ו־Regex היסטורי ללא קריאת רשת. מקור המפתח הוא `.env` מקומי; לפני שליחת נתוני צד שלישי יש לוודא הרשאות.

## מדיניות והחלטות

`config/pricing_policy.json` היא המדיניות הפעילה: קומה 1% לקומה ביחס לקומה 1; מזרח 1%, מערב 2%, צפון ‎−1%, דרום 0%. פרמיות פרוקסי לדופלקס ולטריפלקס הן 10% ו־15%; מרפסת וגינה הן רגישות בלבד. מקדמים אלה **ניסיוניים ולא מכוילים**. `research_baseline_policy.json` היא מדיניות היסטורית לבחירה מפורשת בלבד. פרטי המדיניות האפקטיבית וה־hash נשמרים ב־manifest.

אומדן שווי, טווח, תרחישי מחיר, תרחיש אינדיקטיבי, המלצת פתיחה שעברה שערי החלטה ואישור אנושי הם קטגוריות נפרדות. סכומי תרחישים אינם תחזית הכנסות. מחירי היצע ללא שטח או תאריך מקור מאומת אינם הופכים כשירים רק משום שנאספו ב־snapshot.

## בדיקות

```bash
cd poc
uv sync --locked
uv run --locked pytest -q -rs
```

לשחזור רגישות מדיניות על אותו קלט ו־snapshot, ללא שינוי הקבצים או המדיניות הפעילה:

```bash
cd poc
uv run --locked python scripts/policy_sensitivity.py --snapshot /path/to/market-snapshot.json --workbook ../DATA/חוברת1.xlsx --policy config/pricing_policy.json
```

הפלט משווה בנפרד מקדם קומה אפס ו־2%, קומה וכיוון מאופסים, ואיסור שימוש בשטח מדווח לא מאומת. אלה ניסויי רגישות ולא כיול או רווחי סמך; גם benchmark במצב שטח מחמיר אינו בהכרח מאומת.

בדיקות ה־AI משתמשות ב־mock ואינן מבצעות קריאות חיצוניות. חלק מבדיקות המערכת דורשות snapshot מקומי וקובץ Excel; אין להניח שכל הבדיקות ירוצו בעותק חדש ללא נתונים פרטיים. קובץ התמהיל אינו כלול ונדרש בנפרד לבדיקות התלויות בו. להרצת אינטגרציה אמיתית יש להשתמש בפקודה הראשית ובמפתח תקין; סטטוס, מודל, זמן וטוקנים נשמרים כאשר זמינים.

## מבנה וגבולות

`src/gabay_pricing/` כולל `ingestion`, `normalization` ו־`providers`, `matching`, `valuation`, `unit_adjustments`, `strategy`, `pricing_decision`, `ai_analysis` ו־`reporting`. ניסויים היסטוריים שמורים ב־`legacy/`, מחוץ למסלול המוצר. מתודולוגיה והנחות: `ASSUMPTIONS_AND_LIMITATIONS.md` ו־`PRICING_ANALYSIS.md` מופקים לכל הרצה בתיקיית הדוחות.

אסור להעלות מפתחות, `.env`, snapshot של ספק, תגובות מקור או דוחות שכוללים מידע צד שלישי ללא הרשאות. snapshot, מחקר אופציונלי, קובצי Excel ותוצרים מוחרגים מ־Git. אין לשלוח מידע ל־Groq ללא בסיס מתאים וזכויות שימוש.
